# Diagnóstico diferencial de la oftalmoplejía dolorosa

Con criterios ICHD-3 de **especificidad ~50%** ([[Criterios ICHD-3 13.8]]), esta página no es un
apéndice del [[Sindrome de Tolosa-Hunt]]: es la mitad del trabajo diagnóstico. THS es un
diagnóstico de exclusión, y aproximadamente la mitad de quienes cumplen criterios tienen otra cosa
([[2026-08-06 Tolosa-Hunt sintesis clinica]] §6).

## Causas por grupo (ref [2])

| Grupo | Entidad | Qué la sugiere frente a THS |
|---|---|---|
| **Vascular** | Aneurisma de comunicante posterior | Midriasis con compromiso pupilar precoz, cefalea en trueno |
| | **Aneurisma de ACI cavernosa** | Presentación idéntica descrita (ref [4]); angio obligatoria |
| | Fístula carótido-cavernosa | Soplo, quemosis, ingurgitación epiescleral, **VOS dilatada** |
| | Trombosis de seno cavernoso | Fiebre, compromiso bilateral, foco séptico |
| | Neuropatía isquémica diabética | **Respeta la pupila**, dolor menor, resolución espontánea en semanas |
| **Infecciosa** | **Mucormicosis / aspergilosis** | Inmunosupresión o diabetes, enfermedad de senos paranasales, destrucción ósea, escara necrótica. **No revierte con esteroides** |
| | Sinusitis, periostitis, celulitis orbitaria | Fiebre, leucocitosis, foco evidente |
| | Herpes zóster | Erupción en V1, dolor neuropático |
| | Tuberculosis | Contexto epidemiológico, compromiso meníngeo |
| **Inflamatoria** | **[[Enfermedad relacionada con IgG4]]** | Progresiva, multiorgánica, glándulas lagrimales simétricas, bilateral |
| | Sarcoidosis | Engrosamiento dural, realce leptomeníngeo, nervios craneales engrosados, enfermedad pulmonar |
| | Granulomatosis con poliangeítis | **T2 marcadamente hipointenso**, senos paranasales y órbita, ANCA |
| | Arteritis de células gigantes | >50 años, VHS muy alta, claudicación mandibular |
| | Síndrome inflamatorio orbitario | Solapamiento conceptual con el propio THS |
| | Paquimeningitis hipertrófica | Engrosamiento dural difuso |
| **Neoplásica** | **Linfoma** | Agranda el seno **sin comprimir la ACI**, extensión por forámenes. Puede responder inicialmente a esteroides — falso positivo clásico |
| | Carcinoma nasofaríngeo | Población de riesgo, adenopatías, extensión por base de cráneo |
| | Meningioma | **Base dural ancha, cola dural**; estrechamiento de ACI que no revierte |
| | Metástasis paraselar/orbitaria, mieloma | Neoplasia conocida, lesiones óseas |
| | Adenoma hipofisario | Engloba la ACI sin estrecharla, alteración endocrina |
| **Otras** | Neuropatía oftalmopléjica dolorosa recurrente | Episodios estereotipados desde la infancia, realce del III par en su origen |
| | Síndrome de ápex orbitario | Superposición anatómica; el compromiso del II par lo define (ref [5]) |
| | Trauma | Antecedente |

## Los tres que hay que descartar activamente

1. **Infección fúngica** — es la que mata rápido y la que empeora con el tratamiento del THS.
   Diabetes o inmunosupresión + enfermedad paranasal + destrucción ósea: hongos hasta que se
   demuestre lo contrario.
2. **Linfoma** — responde inicialmente a esteroides, lo que produce el falso positivo clásico. El
   patrón de imagen ayuda: agranda el seno sin comprimir la ACI.
3. **[[Enfermedad relacionada con IgG4]]** — clínicamente casi idéntica; sin biopsia no se
   distingue con certeza.

## La discriminación por imagen vascular

El comportamiento de la ACI cavernosa separa varias de estas entidades y está tabulado en
[[RM de seno cavernoso]]. Regla corta: **estrechamiento que revierte con esteroides** apoya THS;
que no revierta, o que la arteria esté englobada sin estrecharse, apunta a otra cosa.

## Orden práctico de estudio

Ver [[Oftalmoplejia dolorosa]] para el algoritmo. El punto no negociable: **corticoides al final,
no al principio**, y seguimiento mínimo 2 años aunque todo apunte a THS.
